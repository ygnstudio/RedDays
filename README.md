# RedDays

中国法定节假日、香港公众假期与历法类日历的苹果日历订阅源，全部自动更新。日历里只有红日子（法定假日和调休补班），没有普通周末的噪音。

## 大陆法定节假日

**标题**（月视图一眼可读）：

```
春节 假 2/9        ← 假期第 2 天，共 9 天
春节 补 1/2        ← 为春节补班，共 2 天中的第 1 天
国庆节 补 2/2      ← 10/10，本次假期最后一个补班日
```

**描述**（点开事件看全上下文）：

```
「春节」假期第2天（共9天）
假期：2月15日至2月23日
调休补班：2月14日、2月28日
下一个假期：清明节（4月4日至4月6日）
依据国务院办公厅通知: https://www.gov.cn/...
```

| 版本 | 内容 | 适合 |
|---|---|---|
| **详细版** | 假期每天一条（`春节 假 2/9`），补班带 09:00-18:00 时间与前一晚 21:00 提醒 | 临近假期看进度、补班闹钟 |
| **极简版** | 仅假期首日（`春节（休）`）与补班日（`春节（班）`），全年约 13 条 | 平时保持日历干净 |
| **补班版** | 只有调休补班日（`春节 补 1/2`），不含任何放假，同样带时间与提醒 | 放假自己记得住、只怕忘了补班 |

建议详细版和极简版都订，平时只开极简版，放假前打开详细版。补班版供单订补班提醒的人选用。

|---|---|---|
| **大陆法定节假日** | 假期与调休补班，三版本见上 | 国务院办公厅公告原文，事件附通知链接 |

| **香港公众假期** | 全年公众假期，简体（`reddays-hk.ics`）与繁體（`reddays-hk-tc.ics`）两版，任选其一 | 香港特区政府 1823 官方名单 |
| **民族节日** | 开斋节、古尔邦节、藏历新年、泼水节、火把节、彝历新年 | 藏历新年与西藏自治区藏医院《西藏天文气象历书》一致；泼水节、彝历新年按地方政府公告口径；开斋节、古尔邦节以见月官宣为准，个别年份比推算晚一天，描述内已标注 |
| **回历每日** | 每天一条带回历日期，斋月、开斋节、古尔邦节等纪念日写入标题 | 沙特官方 Umm al-Qura 历法，日常换算即官方口径 |
| **基督教历** | 复活节及受难节、升天节等关联节日，加圣诞相关，全年 9 条 | 复活节日期由教会法固定算法规定，算出即官方日期；西方教会口径 |

## 添加方式

macOS「日历 → 文件 → 新建日历订阅（⌥⌘S）」粘贴链接；或把 `https://` 换成 `webcal://` 直接点开。

## 常见问题

- **为什么没有普通周末？** 「与周末连休」的周末不是法定节假日，国务院数据不含，本日历照实呈现（依据[《全国年节及纪念日放假办法》](https://www.gov.cn/zhengce/content/202411/content_6986380.htm)）
- **明年怎么是空的？** 次年安排以国务院公告为准（历年 10 月下旬到 12 月上旬发布），发布后最坏约 12 小时内自动解析上线；机器校验发现异常会拦下发布并开告警 issue
- **改了订阅手机没变？** iOS 订阅刷新由系统调度（数小时到一天）；Mac 可右键日历 → 刷新。UID 稳定，删除重加不会重复
